## 一、扣子（Coze）是什么？

**扣子（Coze）** 是字节跳动旗下的一站式 AI 智能体（Agent）开发与协作平台，底层基于豆包 Seed 大模型体系。它让用户无需编程基础，通过可视化拖拽和简单配置，就能快速搭建聊天机器人、个人助手、自动化工作流等 AI 应用，并一键发布到豆包、飞书、微信公众号等多个平台。

> 扣子于 2025 年 7 月正式开源（Apache 2.0 协议，可商用），2026 年已迭代至 3.0 版本，支持手机端（iOS/Android）、电脑端（Mac/Windows）及网页端全平台使用。

### 核心能力

| 模块 | 说明 |
| --- | --- |
| **智能体（Agent）** | AI 大脑，负责人设、逻辑与对话交互，支持多模型切换和长期记忆 |
| **知识库（RAG）** | 上传 PDF、Word、Excel 等文件，让 Agent 基于你的私有资料精准回答 |
| **工作流（Workflow）** | 可视化拖拽搭建复杂自动化流程，是扣子最核心的能力 |
| **插件生态** | 内置 60+ 官方插件，也支持自定义 API 插件扩展能力 |
| **多端发布** | 一键部署到豆包、飞书、微信、网页等渠道 |
| **项目空间** | 3.0 新增，支持多 Agent 分工协作，人与 Agent 在同一空间共同推进任务 |

### 扣子能做什么？

- **日常办公**：收发邮件、日程管理、文件处理、会议纪要
- **内容创作**：写文案、做 PPT、生成图片、制作播客和短视频
- **数据分析**：财报分析、报表自动化、市场调研
- **编程开发**：对话式开发网页、App、小程序，支持本地 Agent 接入
- **自动化任务**：定时执行、后台运行，7×24 小时不间断工作

## 二、扣子的安装

扣子提供多种使用方式，下面分别介绍**桌面客户端安装**、**移动端安装**和**网页版直接使用**。

### 方式一：桌面客户端（推荐）

扣子桌面端支持 Windows 和 macOS，安装后 Agent 可以获得授权读取和处理你电脑上的本地文件，体验最完整。

#### Windows 安装

1. **下载安装包**
   - 访问扣子官网下载页面：[https://www.coze.cn/overview](https://www.coze.cn/overview)
   - 点击「下载客户端」，选择 Windows 版本（当前最新版约 162 MB，支持 Win10 / Win11）

2. **运行安装程序**
   - 双击下载的 `.exe` 安装包
   - 按提示完成安装，可自定义安装路径

3. **登录账号**
   - 打开扣子，使用手机号或抖音账号登录
   - 首次登录需完成实名认证

4. **授权本地设备**
   - 登录后，按引导授权 Agent 访问本地文件夹
   - 授权后 Agent 即可读取、处理你电脑上的文件

#### macOS 安装

1. 访问 [https://www.coze.cn/overview](https://www.coze.cn/overview)，下载 Mac 版（`.dmg`）
2. 打开 `.dmg` 文件，将扣子拖入「应用程序」文件夹
3. 启动扣子，登录账号并完成授权即可

> 💡 **提示**：桌面端支持云盘双向同步，本地文件与云端自动同步，手机和多台电脑之间可以无缝接力。

### 方式二：手机 App

在手机应用商店搜索「**扣子**」或「**扣子-AI办公伙伴**」，下载安装后登录同一账号即可：

- **iOS**：App Store 搜索下载
- **Android**：各大应用商店搜索下载

手机端支持远程指挥 Agent 处理电脑上的任务，出门在外也能随时查看进度、追加指令。

### 方式三：网页版（免安装）

如果不想安装客户端，直接用浏览器访问即可：

- 国内版：[https://www.coze.cn](https://www.coze.cn)
- 直接使用手机号或抖音账号登录，功能完整，自动更新

网页版适合临时使用或不方便安装软件的场景。

## 三、快速上手

安装完成后，三步即可开始使用：

1. **创建或选择 Agent**：可以从模板市场选择现成的助手，也可以从零创建专属 Agent
2. **下达任务**：用自然语言描述你的需求，比如"帮我整理这份 Excel 数据并生成图表"
3. **查看结果**：Agent 会自动规划并执行，完成后交付结果

你还可以在「项目空间」中组建多个 Agent 团队，让它们分工协作完成复杂任务。

## 四、开源版本地部署（可选）

对于有技术基础、希望私有化部署的用户，扣子开源了 **Coze Studio**（开发平台）和 **Coze Loop**（运维管理平台），采用 Apache 2.0 协议。

**最低配置要求**：2 核 CPU、4 GB 内存，预装 Docker 和 Docker Compose。

**快速部署步骤**：

```bash
# 1. 克隆源码
git clone https://github.com/coze-dev/coze-studio.git

# 2. 进入 docker 目录并复制配置
cd coze-studio/docker
cp .env.example .env

# 3. 配置模型（复制模型模板并填入 API Key）
cp ../backend/conf/model/template/model_template_ark_doubao-seed-1.6.yaml \
   ../backend/conf/model/ark_doubao-seed-1.6.yaml
# 编辑该文件，填入你的模型 API Key

# 4. 启动服务
docker compose --profile "*" up -d
```

启动成功后，浏览器访问 [http://localhost:8888](http://localhost:8888) 即可使用本地部署的扣子。

> 开源仓库地址：[https://github.com/coze-dev/coze-studio](https://github.com/coze-dev/coze-studio)
