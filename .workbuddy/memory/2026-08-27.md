# 修复评论区与友链头像加载失败

## 问题描述
- 评论区头像显示破损图标（Waline 默认使用国外 Gravatar/Libravatar 源，国内访问不稳定）
- 友链中「wrCBDjdh的博客」和「日和」头像无法渲染（外链失效或触发防盗链）

## 修复内容

### 1. 评论区头像
**文件**: `themes/kuri/layout/_partial/comments.ejs`
**修改**: 在 Waline `init()` 配置中新增 `avatarCDN` 字段，指向国内 Gravatar 镜像：
```javascript
avatarCDN: 'https://cravatar.cn/avatar/'
```
> 说明：Waline v3 客户端默认使用 `https://sdn.geekzu.org/avatar/`，但该源在国内也可能不稳定。`cravatar.cn` 是国内较稳定的公益 Gravatar 镜像。

### 2. 友链头像
**文件**: `themes/kuri/layout/_partial/friends-main.ejs`
**修改**: 为友链头像 `<img>` 标签增加 `onerror` 回退：
```html
<img onerror="this.src='/images/avatar.jpg'" ... />
```
> 说明：当外链头像 404 或被防盗链拦截时，自动降级显示主题自带的默认头像 `/images/avatar.jpg`。
