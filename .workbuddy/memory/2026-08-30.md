# 2026-08-30

## Waline 头像 CDN 修正（comments.ejs）

- 用户反馈友链里"羊角快车Blog"评论区所有头像加载失败（截图显示）。
- 该问题在羊角博客自身，用户改不了，所以不在本地修。
- 但发现本地 `themes/kuri/layout/_partial/comments.ejs` 用了 `avatarCDN: 'https://cravatar.cn/avatar/'`，而 cravatar.cn 已 301 永久跳转到 `cn.cravatar.com`，部分浏览器/CDN 跟随重定向不稳，长远也会出同样问题。
- 修复：
  1. 将 `avatarCDN` 改成 `https://cn.cravatar.com/avatar/`（直接走最终地址）。
  2. 增加 `defaultAvatar: 'identicon'` 作为未注册访客的兜底几何头像，避免再出现"破图标"。
- 提示用户重新生成静态页（hexo clean && hexo generate && hexo deploy）后生效。

## 给用户的替代方案（给以后选型）

- 想彻底解决"外部头像依赖"问题，可以换自托管评论：Artalk（全自托管，可代理头像）、Twikoo（Vercel 部署，邮箱 → Cravatar 全自动）。
- 想保留 Waline 但彻底去外链：把 `avatarCDN` 换为自己反向代理 `https://<CDN>/avatar/`，再把 `defaultAvatar` 指向本地默认图。
