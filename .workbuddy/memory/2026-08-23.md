## 复制按钮升级：适配 figure.highlight 结构

- 用户截图反馈代码块没有按钮。根因：hexo 默认 highlight 渲染输出的代码块是 `<figure class="highlight"><table><tr><td class="code"><pre></pre></td></tr></table></figure>`，外面包了 figure，且按钮之前默认 `opacity: 0` 仅 hover 才显示，用户没意识到有按钮
- 修复：JS 选择器改为 `.post-content figure.highlight, .post-content pre`（兼容两种结构）；代码提取路径 `td.code > pre code > pre > innerText` 兜底
- 样式：按钮改为 `background: rgba(102,204,255,0.85)` 蓝色，默认 `opacity: 0.85` 始终可见，不再依赖 hover；hover 时变实色并轻微上浮
- JS 重构：用 DOMContentLoaded 包装避免时机问题；按钮去重检查；extract text 用 innerText 去 nbsp；clipboard API 不可用时降级到 textarea + execCommand
- 在 .post-content figure.highlight 和 .post-content pre 都加 position: relative 作为按钮定位锚点
